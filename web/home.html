Draw together, in one click.

A whiteboard for sketching, planning and thinking out loud. Drop in images and GIFs, watch everyone's cursors move live, and share it with a link. No accounts, no install.

What's in it

Everything for a quick sketch or a long brainstorm

Infinite canvas, the tools you expect, and nothing in the way.

Pen, highlighter, eraser

Smooth strokes in eight colours and three sizes. Erase by dragging over an object.

Shapes and arrows

Lines, arrows, rectangles and ellipses. Select any of them to move, resize or recolour.

Text and sticky notes

Click anywhere and type. Notes wrap their text and resize with a handle.

Images and GIFs

Drop, paste, upload or add by link. GIFs keep playing right on the board.

Live together

See each other's cursors and edits as they happen, with names and colours.

Undo and redo

Take back your own changes without touching anyone else's work.

Saved automatically

Come back to the same link tomorrow and your board is still there.

Export to PNG

Save the whole board as a picture with one click.

No accounts

Pick a name and go. Boards are private to whoever has the link.

See it

Built for the way you actually sketch

Everything below is a recording of the real app, not a mock-up.

Sketch freely, tidy later

Switch tools with one key and keep drawing. Shapes give you clean outlines while the pen stays loose.

  • P pen, H highlighter, E eraser
  • L line, A arrow, R rectangle, O ellipse
  • Ctrl+Z to undo, Space to pan

Pictures and GIFs, not just lines

Drag a file onto the board, paste from your clipboard, or paste a link. Resize and move it like anything else. Animated GIFs keep moving.

  • PNG, JPEG, GIF and WebP up to 10 MB
  • Uploads stay on the server you run
  • Pin sticky notes right next to them

Self-host

Run it yourself in a minute

Put it on a small server, a spare Raspberry Pi, or your own machine. Your boards and uploads stay in one folder.

From source

# inside the Scrawl source folder
cargo run --release
# open http://localhost:7878

With Docker

docker build -t scrawl .
docker run -p 7878:7878 \
  -v scrawl-data:/data scrawl

Set SCRAWL_ADDR to choose the port and SCRAWL_DATA for the data folder. Behind a reverse proxy, forward WebSocket upgrades on /ws/*.

Questions

Good to know

Who can see or edit my board?

Anyone who has the link. The board code in the address is the only access control, so treat the link like an unlisted document. There are no passwords or accounts yet.

Do I need to sign up?

No. You pick a display name the first time and that is it.

How do I add a GIF?

Drag the file onto the board, paste it, use the image button to upload, or use the globe button to paste a direct link ending in .gif. Search sites like Tenor and Giphy need their own API keys, so they are not built in.

Does it work on phones and tablets?

The interface adapts to small screens and uses touch pointers with pinch zoom. It has been written for touch but not yet tested on real devices, so expect rough edges.

Where is my data stored?

On the server running Scrawl, as one JSON file per board plus the images that were uploaded. Nothing is sent to third parties.
